# UPBGE Multiplayer Online

**UPBGE Multiplayer Online** is a base for creating online multiplayer games using **100% custom-made code**. It is a free and open-source Python project, designed and tested on **UPBGE 0.2.4x** (Blender Game Engine - BGE).

## Introduction

**UPBGE Multiplayer Online** provides a solid foundation for developing online multiplayer games. If you're new to UPBGE or looking to create a multiplayer game from scratch, this repository is the perfect starting point.

## Features

- Online multiplayer functionality  
- Custom-made Python code for game development  
- Free to use and modify  
- Compatibility with UPBGE 0.2.4x
